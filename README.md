# tofo-list-app

A simple Python To-Do List application with a menu-based interface.

## Features
- Add tasks
- View tasks
- Delete tasks
- Save tasks to a text file (`tasks.txt`)
- Load existing tasks when the program starts

## Run the app

```bash
python3 todo_app.py
```

## Menu options
1. Add task
2. View tasks
3. Delete task
4. Exit
